# The Football Page

Eine Fussball-Webseite als Einzelprojekt (Portfolio auf GitHub Pages).

## Ziel

- **Aktuelle Spiele:** Alle Spiele und Ligen des Tages auf der Startseite
- **Lieblingsteams:** Teams suchen, als Favoriten speichern und jederzeit anpassen
- **Tabellen:** Die Ligatabellen der Lieblingsteams

## Technik

Reines HTML, CSS und JavaScript (ohne Framework).
